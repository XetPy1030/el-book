## SDK — на чём пишутся приложения

| Путь | Что там | С чего начать |
|---|---|---|
| `sdk/device` | интерфейсы устройства: экран, события, подсветка, батарея, сон, Wi-Fi; общие типы событий и ошибки сети | `sdk/device/device.go` → `Device` |
| `sdk/device/kobo` | Kobo Forma: модель и её квирки, структуры ioctl EPDC, разбор evdev и snow-протокола тача, подсветка и батарея через sysfs, сон, Wi-Fi через `wifi.sh` и управляющий сокет `wpa_supplicant`. Системные вызовы — только в файлах `*_linux_arm.go` | `sdk/device/kobo/model.go` → `forma` |
| `sdk/device/emu` | эмулятор книги: панель с имитацией waveform, имитация Wi-Fi, веб-страница, скрипты действий | `sdk/device/emu/emu.go` → `New()` |
| `sdk/eink` | классы изменений и выбор waveform, слияние областей, частота полной очистки, планировщик обновлений | `sdk/eink/eink.go` → `Scheduler` |
| `sdk/gfx` | холст в оттенках серого, фигуры со сглаживанием, контуры, шрифты Fira Sans и Go Mono, текст, картинки, дизеринг для двухцветных режимов | `sdk/gfx/canvas.go` → `Canvas` |
| `sdk/icons` | линейные иконки на сетке 24×24, рисуются в любом размере | `sdk/icons/icons.go` → `Drawer` |
| `sdk/ui` | тема в миллиметрах и пунктах, распознавание жестов, страница виджетов, виджеты, клавиатура, текст страницами, диалоги, меню и тосты | `sdk/ui/page.go` → `Page` |
| `sdk/kit` | готовые экраны и помощники: список, чтение страницами, ввод текста, загрузка в фоне, настройки приложения с версией | `sdk/kit/list.go` → `ListScreen` |
| `sdk/ink` | рисование: штрихи и кисти, сглаживание, распознавание фигур, лассо, формат хранения, SVG и PDF | `sdk/ink/ink.go` → `Stroke` |
| `sdk/web` | HTTP-клиент приложения: сеть по требованию, кэш, работа без сети, понятные ошибки; текст статьи из HTML | `sdk/web/web.go` → `Client` |
| `sdk/ru` | русский текст: числа с падежами, даты, дни недели, размеры, десятичная запятая | `sdk/ru/ru.go` → `Count()` |
| `sdk/app` | контракт приложения, цикл событий, стеки экранов, контекст приложения, системные возможности оболочки | `sdk/app/loop.go` → `Run()` |
| `sdk/storage` | хранилище приложения: настройки с версией, документы, кэш, выгрузка, атомарная запись | `sdk/storage/storage.go` → `WriteAtomic()` |

Опорные места внутри пакетов:

- выбор waveform по классу и полная очистка — `sdk/eink/eink.go` → `Plan()`;
- склейка штрихов перед отправкой на панель — `sdk/app/loop.go` → `gateStrokes()`;
- перехват паник приложения — `sdk/app/loop.go` → `safe()`;
- запуск, «домой» и закрытие лишних приложений — `sdk/app/stack.go` → `launch()`;
- сеть по требованию приложения — `sdk/app/loop.go` → `connect()`;
- сообщение об ошибке пользователю и в журнал — `sdk/app/context.go` → `Fail()`;
- жесты из касаний — `sdk/ui/gesture.go` → `Recognizer`;
- растеризация штриха — `sdk/ink/raster.go` → `capsule()`;
- текст статьи со страницы — `sdk/web/html.go` → `ExtractText()`;
- поворот фреймбуфера с проверкой — `sdk/device/kobo/display.go` → `SetRotation()`;
- разбор касаний Forma — `sdk/device/kobo/input.go` → `touchParser`;
- сон: пауза после экрана, повторы при отказе ядра, отмена и ложные пробуждения — `sdk/device/kobo/power.go` → `Suspend()`;
- подключение к сети Wi-Fi, неверный пароль — `sdk/device/kobo/wifi.go` → `waitAssociated()`;
- открытие книги — `sdk/device/kobo/device_linux_arm.go` → `Open()`.

## Сборка, запуск, проверки

| Путь | Что там | С чего начать |
|---|---|---|
| `cmd/el-book` | бинарник для книги: журнал, слой Kobo, хранилище, оболочка | `cmd/el-book/main.go` → `run()` |
| `cmd/emulator` | бинарник эмулятора: браузер или скрипт со снимками | `cmd/emulator/main.go` → `runScript()` |
| `scripts/device` | скрипт запуска вместо Nickel, Wi-Fi, сбор данных, пункты NickelMenu, проверки скриптов с заглушками | `scripts/device/launch.sh` → `start_nickel()` |
| `emulator/scripts` | сценарии эмулятора; по ним идут UI-тесты | `emulator/scripts/smoke.txt` → `shot 09-settings` |
| `internal/uitest` | UI-тесты: прогон сценариев, ответы сети из файлов, сравнение снимков с эталонами в `testdata` | `internal/uitest/uitest_test.go` → `compare()` |
| `tools/doccheck` | проверка документации | `tools/doccheck/checks.go` → `checkCodeRefs()` |
| `tools/archcheck` | проверка правил кода по исходникам | `tools/archcheck/check.go` → `layerViolation()` |
| `tools/sheet` | лист с иконками и шрифтами для глазной проверки | `tools/sheet/main.go` → `main()` |

Цели сборки и проверок — в `Makefile`; как ими пользоваться — в руководствах
[«Разработка в эмуляторе»](../guides/Разработка%20в%20эмуляторе.md) и
[«Установка на книгу»](../guides/Установка%20на%20книгу.md).

## Куда класть новый код

| Что | Куда |
|---|---|
| новое приложение | `apps/<id>/`, регистрация — `internal/builtin/builtin.go` → `Apps()` |
| экран, нужный двум приложениям: список, чтение, ввод | `sdk/kit` |
| виджет, нужный двум приложениям | `sdk/ui` |
| кисть, фигура, формат выгрузки рисунка | `sdk/ink` |
| разбор ответа сервера | в пакет приложения, с тестом на сохранённом ответе |
| факт о железе: путь sysfs, код кнопки, квирк | `sdk/device/kobo`, в описание модели |
| системный вызов | `sdk/device/kobo`, файл `*_linux_arm.go` |
| системная функция для всех приложений: сон, USB, подсветка, Wi-Fi | `shell` |
| сценарий для UI-теста | `emulator/scripts/<имя>.txt`, эталоны — `internal/uitest/testdata/<имя>/`, ответы сети — `internal/uitest/testdata/http/` |
