# Глоссарий

**Тип:** справочник · **Аудитория:** все участники проекта, ИИ-агенты · **Статус документа:** живой · **Актуально на:** 20.10.2026

**Когда читать:** встретили в документации или коде незнакомый термин про Kobo, e-ink или проект.

---

| Термин | Значение |
|---|---|
| **A2, DU** | быстрые двухцветные waveform-режимы: для отклика на касание и штрихов |
| **ADR** | запись архитектурного решения: контекст, выбор, отвергнутые варианты; лежит в `docs/adr/` |
| **EPDC** | контроллер e-ink-панели в процессоре i.MX; им управляют ioctl фреймбуфера |
| **evdev** | интерфейс ядра Linux для устройств ввода: файлы `/dev/input/event*`, события «тип, код, значение» |
| **EVIOCGRAB** | ioctl монопольного захвата устройства ввода: события перестают уходить другим процессам |
| **FBInk** | C-библиотека и утилита вывода на e-ink-экраны; эталон номеров ioctl и квирков моделей |
| **GC16, GL16, REAGL** | 16-оттеночные waveform-режимы: чистый, щадящий для текста и с подавлением следов |
| **ghosting** | бледные следы прошлой картинки после частичных обновлений; убираются полным обновлением |
| **KFMon** | демон, запускающий скрипт, когда Nickel открывает определённый PNG-файл как книгу |
| **KoboRoot.tgz** | архив, который Nickel распаковывает в системный раздел при загрузке; так ставятся моды вроде NickelMenu |
| **launch.sh** | скрипт запуска платформы: останавливает Nickel, запускает оболочку и по коду выхода выключает, перезагружает книгу или возвращает Nickel |
| **Mark 7** | поколение платформы Kobo, к которому относится Forma; определяет вариант ioctl обновления экрана |
| **multitouch protocol B** | способ, которым тачскрин сообщает о пальцах: слоты и `ABS_MT_TRACKING_ID` |
| **Nickel** | штатная программа Kobo: библиотека, читалка, магазин, синхронизация |
| **NickelMenu** | мод, добавляющий пункты в меню Nickel; через него запускается оболочка |
| **onboard** | пользовательский раздел книги, смонтирован в `/mnt/onboard`, виден по USB |
| **PSK** | ключ сети WPA: 32 байта, вычисленные из пароля и имени сети; оболочка хранит его вместо пароля |
| **SDK** | пакеты `sdk/...`: экран, ввод, виджеты, хранилище — всё, на чём пишутся приложения |
| **snow-протокол** | вариант multitouch у тачскрина Forma (название из KOReader): без слотов, номер пальца — `TRACKING_ID`, подъём — только `BTN_TOUCH` = 0 |
| **sysfs** | файлы в `/sys`, через которые читают и меняют параметры ядра и железа: подсветка, батарея, сон |
| **wakeup_count** | счётчик событий пробуждения ядра; платформа его не сверяет: KOReader отключил сверку, на части книг после неё книга сразу просыпается |
| **waveform** | последовательность напряжений, которой контроллер переводит пиксели e-ink из одного оттенка в другой |
| **wifi.sh** | скрипт платформы, который включает Wi-Fi (модули, интерфейс, `wpa_supplicant`), получает адрес и выключает всё обратно |
| **wpa_supplicant** | служба Linux, которая подключает Wi-Fi к сети; оболочка управляет ею через управляющий сокет |
| **выгрузка** | папка `data/export/<приложение>/`, куда приложения кладут файлы для компьютера: PNG рисунков, отчёты |
| **диагностика** | экран оболочки в настройках: сведения об устройстве, проверка касаний и поворотов, замер скорости панели, отчёт |
| **жест от края** | свайп от верхнего края (шторка) или от нижнего (домой); работает поверх любого приложения |
| **канонический поворот** | значение поворота экрана в терминах FBInk и KOReader: положение книги, без поправок модели; поворот в SDK — это поворот содержимого |
| **кисть** | способ рисовать штрих в рисовалке: ручка, перо, маркер, карандаш, набросок, паутина, мех |
| **квирк** | особенность конкретной модели, которую приходится обходить отдельным кодом |
| **класс изменения** | то, что приложение сообщает SDK вместо waveform: отклик, интерфейс, контент, штрих, очистка |
| **код выхода** | число, которым оболочка говорит скрипту запуска, что делать: 0 — вернуть Nickel, 10 — выключить книгу, 11 — перезагрузить |
| **лассо** | выделение штрихов обводкой пальцем: выделенное двигают, копируют, удаляют |
| **ложное пробуждение** | пробуждение книги не пользователем — например, от зарядника; слой Kobo усыпляет книгу снова |
| **маркер обновления** | число, которое контроллер e-ink присваивает обновлению; по нему ждут конца именно этого обновления |
| **ночной режим** | весь интерфейс светлым по тёмному: оболочка инвертирует картинку перед отправкой на панель |
| **оболочка** | наш процесс на книге: владеет устройством, показывает домашний экран, запускает приложения |
| **открытое приложение** | запущенное приложение, из которого ушли: оно остаётся в памяти со своими экранами ([ADR-0007](../adr/ADR-0007%20Приложения%20остаются%20открытыми.md)) |
| **полное и частичное обновление** | перерисовка всех пикселей области с миганием или только изменившихся без него |
| **приложение** | Go-пакет на SDK, встроенный в оболочку; например, рисовалка |
| **разметка** | фон страницы тетради: линейка, клетка, точки, косая линейка, нотный стан |
| **сводка** | строка приложения справа от часов на домашнем экране; приложение даёт её, не будучи запущенным |
| **снимок** | документ с фактами на дату; не обновляется, а вытесняется более свежим |
| **спайк** | маленький эксперимент на книге, проверяющий один механизм до того, как на нём строить код |
| **тетрадь** | документ рисовалки: страницы, у каждой своя разметка |
| **шторка** | быстрые настройки сверху экрана: подсветка, Wi-Fi, ночной режим, сон, Nickel и открытые приложения |
| **эталонный снимок** | PNG, с которым UI-тест сравнивает снимок эмулятора; лежит в `internal/uitest/testdata/` |
