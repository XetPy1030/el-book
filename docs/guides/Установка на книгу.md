# Установка на книгу

**Тип:** руководство · **Аудитория:** владелец книги · **Статус документа:** живой · **Актуально на:** 20.10.2026

**Правила:** [«Правила работы с устройством»](../rules/Правила%20работы%20с%20устройством.md)

**Когда читать:** ставите el-book на книгу впервые, обновляете его или убираете с книги.

---

Установка не трогает системный раздел: на книгу копируются файлы в папку `.adds/el-book/`
и пункт меню в `.adds/nm/`. Удаление — удаление этих файлов. Займёт около пяти минут.

Нужны: репозиторий на Mac с Go (как его настроить — [«Настройка окружения разработки»](Настройка%20окружения%20разработки.md)),
кабель и NickelMenu на книге — он уже стоит. Перед **первым** запуском — заряд не ниже 30 % и свежий
бэкап книг: первый запуск — эксперимент.

## 1. Скопировать файлы

1. Подключите книгу к Mac кабелем и на книге нажмите **Connect**. Появится диск `KOBOeReader`.
2. В терминале, из корня репозитория:

   ```sh
   make deploy-usb
   ```

   Команда соберёт бинарник под книгу и скопирует его вместе со скриптами и пунктом меню.
   Если диск смонтирован не в `/Volumes/KOBOeReader`, укажите путь: `make deploy-usb KOBO_VOLUME=/путь`.
3. Извлеките диск в Finder и отсоедините кабель.

Без среды разработки можно поставить готовый архив: `make package` кладёт его в `dist/`,
а распаковывается он в корень диска книги:

```sh
unzip -o dist/el-book-<версия>.zip -d /Volumes/KOBOeReader
cd /Volumes/KOBOeReader/.adds && rm -f ._el-book el-book/._* nm/._el-book
```

Вторая строка убирает служебные файлы `._*`: macOS создаёт их на диске книги рядом с каждым
новым файлом. `make deploy-usb` убирает их сам.

## 2. Первый запуск

1. На домашнем экране Nickel откройте вкладку **NickelMenu** в правом нижнем углу.
2. Выберите **el-book**.
3. Nickel закроется: пару секунд на экране остаётся его картинка. Затем экран мигнёт и появится
   домашний экран el-book — часы, дата, плитки приложений и панель внизу.

Если через десять секунд ничего не изменилось — держите кнопку питания до перезагрузки:
книга загрузится в Nickel как обычно. Потом заберите журналы (раздел
[«Если что-то пошло не так»](#если-что-то-пошло-не-так)).

## 3. Вернуться в Nickel

Проведите пальцем вниз от верхнего края экрана или коснитесь строки состояния — откроется
шторка. Нажмите **Nickel** и подтвердите. Тот же пункт есть в «Настройки» → «Питание».
Покажется анимация загрузки, затем библиотека Nickel. Книга вернётся в Nickel и сама, если
el-book упадёт.

## 4. Обновить

Повторите шаг 1. Бинарник и скрипты заменятся; настройки и рисунки лежат отдельно и сохранятся.

## Где что лежит на книге

Пути — от корня диска `KOBOeReader` (на самой книге это `/mnt/onboard`).

| Путь | Что это |
|---|---|
| `.adds/el-book/el-book` | бинарник оболочки |
| `.adds/el-book/launch.sh` | скрипт запуска: останавливает Nickel, запускает оболочку, возвращает Nickel |
| `.adds/el-book/probe.sh` | скрипт сбора данных ([руководство](Сбор%20данных%20с%20устройства.md)) |
| `.adds/el-book/wifi.sh` | скрипт Wi-Fi: оболочка включает им Wi-Fi и выключает обратно |
| `.adds/nm/el-book` | пункты NickelMenu: «el-book» и «el-book — сбор данных» |
| `.adds/el-book/logs/el-book.log` | журнал оболочки; вырос больше мегабайта — при запуске уходит в `el-book.log.1` |
| `.adds/el-book/logs/launch.log` | журнал скрипта запуска: остановка и возврат Nickel, коды выхода |
| `.adds/el-book/logs/el-book.out` | всё, что оболочка вывела мимо журнала |
| `.adds/el-book/logs/wifi.log` | вывод скрипта Wi-Fi; вырос больше 256 КБ — при запуске уходит в `wifi.log.1` |
| `.adds/el-book/wifi/networks.json` | сети, добавленные в оболочке: имя и ключ сети, пароля в файле нет |
| `.adds/el-book/data/apps/<приложение>/` | настройки и документы приложений; `shell` — настройки оболочки |
| `.adds/el-book/data/export/<приложение>/` | выгрузка: страницы и тетради рисовалки в PNG, SVG и PDF, заметки в текст, отчёты диагностики оболочки |

## Если что-то пошло не так

- **Экран застыл, книга не отвечает.** Держите кнопку питания до перезагрузки — Nickel загрузится
  как обычно ([аварийный выход](../rules/Правила%20работы%20с%20устройством.md#аварийный-выход)).
- **Пункта el-book нет в меню.** Перезагрузите книгу: NickelMenu читает пункты при загрузке.
- **Журналы для разработчика.** Подключите книгу, скопируйте папку журналов в бэкап — он не попадает в git:

  ```sh
  mkdir -p backup/logs
  cp -R /Volumes/KOBOeReader/.adds/el-book/logs/ backup/logs/
  ```

## Убрать с книги

Удалите папку `.adds/el-book/` и файл `.adds/nm/el-book`, затем перезагрузите книгу.
Вместе с папкой удалятся настройки, тетради, заметки и задачи — выгрузку сначала скопируйте.
