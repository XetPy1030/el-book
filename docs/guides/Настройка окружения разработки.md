# Настройка окружения разработки

**Тип:** руководство · **Аудитория:** разработчики проекта · **Статус документа:** живой · **Актуально на:** 20.10.2026

**Правила:** [«Правила кода»](../rules/Правила%20кода.md), [«Стандарт документации»](../rules/Стандарт%20документации.md)

**Когда читать:** впервые открываете репозиторий на своей машине или проверка перед коммитом упала.

---

## 1. Инструменты

1. Go не ниже версии из `go.mod`: `go version`.
2. git; для работы с книгой по USB — macOS или Linux с доступом к диску `KOBOeReader`.
3. Docker — по желанию: на нём идут две проверки, которых нет в `make check` (раздел 3).

Кросс-тулчейн под ARM не нужен: сборка под книгу — обычный `go build` с переменными окружения
([ADR-0002](../adr/ADR-0002%20Чистый%20Go%20без%20cgo.md)).

## 2. Подключить хук перед коммитом

```sh
make hooks
```

Хук проверяет документацию в том виде, в каком она попадёт в коммит, и правила кода по рабочему дереву.

## 3. Проверить, что всё зелёное

```sh
make check
```

`make check` — это `go vet` под компьютер и под книгу, тесты вместе с UI-тестами, проверка правил
кода `tools/archcheck` и проверка документации по последнему коммиту. Пока в репозитории нет
ни одного коммита, проверяйте документацию по рабочему дереву:

```sh
make check DOCS_SRC=worktree
```

Что значит каждое сообщение проверки документации — в [«Проверке документации»](../reference/Проверка%20документации.md);
сообщение `tools/archcheck` называет номер нарушенного пункта [«Правил кода»](../rules/Правила%20кода.md).

С Docker — ещё две проверки; их стоит запускать после правок слоя Kobo и скриптов для книги:

```sh
make test-kobo      # тесты слоя Kobo на 32-битном ARM
make test-scripts   # launch.sh и wifi.sh с заглушками вместо Nickel и железа, shellcheck
```

## 4. Добавить документ

1. Выберите тип по таблице §1 стандарта и положите файл в каталог этого типа.
2. Начните с шапки по §3 стандарта; H1 — точное имя файла.
3. Добавьте строку о документе в [индекс](../README.md).
4. Если это правило — добавьте его в таблицу `CLAUDE.md`.
5. `make docs-check DOCS_SRC=worktree`.
