# Сбор данных с устройства

**Тип:** руководство · **Аудитория:** владелец книги · **Статус документа:** живой · **Актуально на:** 20.10.2026

**Правила:** [«Правила работы с устройством»](../rules/Правила%20работы%20с%20устройством.md)

**Когда читать:** нужно снять с книги параметры, которых нет в бэкапе, — спайк С1 плана разработки.

---

Скрипт `scripts/device/probe.sh` только читает систему и пишет один текстовый файл на книгу.
Серийный номер и MAC-адреса в файле замаскированы, пароли Wi-Fi не читаются. Займёт около
десяти минут. Что именно он собирает — список в разделе
[«Что не удалось определить»](../reference/Устройство%20Kobo%20Forma%20—%20снимок%2019.10.2026.md#что-не-удалось-определить)
снимка устройства.

## 1. Скопировать файлы на книгу

Скрипт ставится вместе с el-book: выполните шаг 1 [«Установки на книгу»](Установка%20на%20книгу.md#1-скопировать-файлы).
Запускать сам el-book для сбора данных не нужно.

## 2. Запустить сбор

1. На домашнем экране Nickel откройте вкладку **NickelMenu** в правом нижнем углу.
2. Выберите **el-book — сбор данных**.
3. Через несколько секунд появится окно «Готово: .adds/el-book/probe/probe-<дата>.txt» и число строк.
   Около двухсот строк — норма.

Если пункта нет — перезагрузите книгу. Если окно сообщает об ошибке или таймауте — пришлите
его текст разработчику: файл мог записаться частично.

## 3. Забрать результат

1. Подключите книгу кабелем и на книге нажмите **Connect**.
2. Скопируйте файл в папку бэкапа — она не попадает в git:

   ```sh
   mkdir -p backup/probe
   cp /Volumes/KOBOeReader/.adds/el-book/probe/probe-*.txt backup/probe/
   ```

3. Передайте файл разработчику. Перед отправкой его можно просмотреть: это обычный текст,
   разделы начинаются с `=====`.

## Что дальше

Разработчик переносит факты в новый снимок устройства (без секретов), старый снимок уезжает
в архив, а в [журнал разработки](../journal/Журнал%20разработки.md) записывается, что спайк С1 выполнен.

Убрать следы с книги — раздел [«Убрать с книги»](Установка%20на%20книгу.md#убрать-с-книги) установки.
