# Требования к продукту v2

**Тип:** решение · **Аудитория:** владелец проекта и разработчики · **Статус документа:** живой · **Актуально на:** 20.10.2026

**Когда читать:** решаете, что входит во вторую версию — лаунчер, рисовалка, приложения, сеть, — или проверяете её готовность.

---

Разбор [постановки от 20.10.2026](../external/Постановка%20от%2020.10.2026.md). Требования v1 —
в [«Требованиях к продукту v1»](Требования%20к%20продукту%20v1.md): то, что здесь не сказано, остаётся
как там. Документ закрывается вместе с выпуском v2 и уезжает в архив.

Статусы и колонка «Сделано» — как в v1: **принято** — прямо из постановки; **рабочее** — решение
разработчика, принятое без согласования, потому что владелец попросил работать без уточняющих
вопросов; владелец может его пересмотреть. **сделано** — работает в эмуляторе и проверено тестом
или по снимкам UI-тестов; **написано** — код есть, на книге не проверен; **книга** — проверено на книге.

## Продукт одной фразой

Книга как планшет: быстрый лаунчер, мощная рисовалка, приложения на каждый день и интернет —
и SDK, на котором следующее такое приложение пишется за вечер.

## Границы v2

**Входит:** лаунчер v2, рисовалка v2, одиннадцать приложений, Wi-Fi без Nickel, HTTP-клиент
и интеграции с открытыми API без ключей, библиотеки SDK для экранов-списков, чтения, сети и рисования.

**Не входит:** Telegram (В-7 и отдельный ADR о хранении сессии), синхронизация с облаками,
внешние приложения отдельными процессами, обновление по воздуху, другие модели Kobo.

## Рабочие решения 20.10.2026

Владелец попросил не задавать вопросов. Решения, которые он может пересмотреть:

- **Порядок плиток постоянный.** Порядок «недавние первыми» из v1 (О-3) отменён: плитки
  переставлялись после каждого запуска, и касание по памяти попадало в другое приложение.
- **Сводки справа от часов, а не над сеткой**: место под них есть всегда, и сетка не сдвигается,
  когда сводка появляется.
- **На книге Wi-Fi выключен, пока не пройден спайк С11**: подъём Wi-Fi — новое воздействие на
  книгу, и по «Правилам работы с устройством» он сначала проверяется спайком.
- **Ленты по умолчанию** — Хабр, N + 1 и Лента.ру; **город по умолчанию** — Москва.
- **Telegram отложен**: сначала сеть и клавиатура проверяются на простых приложениях.
