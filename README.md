# el-book

Платформа собственных приложений для электронной книги Kobo Forma: быстрая оболочка-лаунчер,
SDK на Go и приложения — первое из них рисовалка.

- Посмотреть без книги: `make emu` и <http://localhost:8740>.
- Поставить на книгу: [«Установка на книгу»](docs/guides/Установка%20на%20книгу.md).
- Вся документация: [docs/README.md](docs/README.md).
