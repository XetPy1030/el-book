# el-book

Платформа собственных приложений для Kobo Forma на Go. Документация и общение — на русском.

Правил в этом файле нет — только маршрут к ним. Начинайте с [индекса документации](docs/README.md).

## Правила

| Правило | Когда применять |
|---|---|
| [Стандарт документации](docs/rules/Стандарт%20документации.md) | пишете или правите любой документ в `docs/` |
| [Правила кода](docs/rules/Правила%20кода.md) | пишете или ревьюите Go-код |
| [Правила интерфейса](docs/rules/Правила%20интерфейса.md) | делаете экран, виджет, реакцию на касание |
| [Правила работы с устройством](docs/rules/Правила%20работы%20с%20устройством.md) | трогаете `backup/`, запускаете что-то на книге или копируете на неё файлы |

## Команды

| Команда | Что делает |
|---|---|
| `make check` | vet под компьютер и книгу, тесты и UI-тесты, правила кода, документация по последнему коммиту |
| `make check DOCS_SRC=worktree` | то же, документация — по рабочему дереву (пока нет коммитов) |
| `make emu` | эмулятор книги в браузере |
| `make uitest-update` | перезаписать эталоны UI-тестов после задуманного изменения интерфейса |
| `make build-kobo`, `make deploy-usb` | собрать бинарник для книги; поставить на подключённую книгу |
| `make test-kobo`, `make test-scripts` | слой Kobo на ARM; скрипты запуска и Wi-Fi с заглушками (нужен Docker) |
| `make hooks` | подключить хук перед коммитом |

Подробнее — [«Настройка окружения разработки»](docs/guides/Настройка%20окружения%20разработки.md).
